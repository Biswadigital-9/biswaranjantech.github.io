# BISWARANJAN TECH – IT Student Learning Hub

BISWARANJAN TECH is an IT Student Learning Hub for notes,
practicals, coding, question banks, cybersecurity learning,
projects and college resources.

## 📁 Project Structure

BISWARANJAN-TECH/
│
├── index.html
├── package.json
├── .env
├── server.js
│
└── public/
    ├── config.js
    ├── app.js
    └── style.css


## 🚀 Installation

First open the project folder in Terminal / CMD.

Run:

npm install


## ▶️ Start Server

Run:

npm start


After starting successfully, open:

http://localhost:5000


## ❤️ API Health Check

Open:

http://localhost:5000/api/health


If everything is working, you should see:

BISWARANJAN TECH API is running 🚀


## 🔐 Authentication

The website supports:

- Student Registration
- Email OTP Verification
- OTP Resend
- Login
- JWT Authentication
- Student Profile
- Logout


## 📧 Email OTP

For real email OTP, configure the `.env` file.

Required:

SMTP_HOST
SMTP_PORT
SMTP_USER
SMTP_PASS

For Gmail:

SMTP_HOST=smtp.gmail.com
SMTP_PORT=587

Use a Gmail App Password for:

SMTP_PASS


## 🗄️ MongoDB

The project uses MongoDB.

Local MongoDB example:

MONGODB_URI=mongodb://127.0.0.1:27017/biswaranjan_tech


## ⚠️ Important Security

Never upload `.env` to GitHub.

Never share:

- Gmail App Password
- JWT Secret
- MongoDB credentials
- API secrets
